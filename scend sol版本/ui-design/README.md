# 三页交互设计稿（等待用户审核）

预览：http://127.0.0.1:8769/three-page-design/index.html

此目录仅为安卓 APP 的交互设计演示。所有数值、警报和记录均为样例；点击开始、连接、删除、导出等不会操作 ESP32、U 盘或真实手机文件。没有制作新版 APK。

## 可审核的页面

- 检测：单屏，电量在连接状态下方；累计尿量、有效时长、流速、滴数、报警与检测控制；快速连接/断开；固定底部检测/记录/设置导航。
- 记录：U盘缓存状态、24小时异常框及逐条删除；简洁检测卡只展示名称、开始时间、状态、修改菜单，整框可点击；改名同步警报名称；清除同时删除全部手机检测记录和警报。
- 详情：统计框的历史警报标红，框下并排红色查看警报与数据分析；警报弹窗限定当前记录；分钟时间戳、增量和速率始终可见，累计量可展开；返回。
- 分析：分钟/小时、尿量/速率/滴数、折线/柱状切换；速率只有折线。整图可点击查看时间点、使用左右方向键；下方有数据表。缺失不补零，跨日显示日期范围。
- 设置：设备连接、设备信息、版本与版本更新、通信记录四个子页及返回；没有模拟演示入口。
- 外部“预览状态”仅用于审核离线、无盘和通知样式，不是正式APP功能。

## 已确认的业务边界

手机与 U 盘各自独立记录。手机只保存接收到的数据；断线显示 Wi-Fi 未连接，缺失时段明确标记，不读取或补传 U 盘。ESP32 通过 CH376T 独立写 U 盘。无盘/写入失败继续检测，并明确“U 盘记录未保存”，不混淆手机保存状态。

开始成功产生记录；暂停/继续属于同一记录；复位确认后正常结束，历史警报保留。手机改名、删除、清除、CSV导出均不修改 U 盘。

单条未结束记录的删除保护仍为设计建议。“清除所有记录”按用户最新要求清空全部手机检测记录和警报，包含当前本地记录，不清零设备读数、不停止设备检测。连接和电量只在检测首页展示；设置首页移除底部小字。更新来源未指定，因此显示尚未设置，不能判断是否有新版本。

## 验证范围

Node语法检查通过。最新浏览器验收包含：改名同步警报名称、记录卡全框点击与独立菜单、32字名称换行不溢出、关联警报弹窗、单条警报删除后计数和详情同步、同时清空两类记录而首页读数保留、设置移除状态和页脚。此前已验收导航、快连、分钟数据、图表切换、速率无柱状、图表键盘选点及无盘继续检测。

最新检测框在线/离线 clientHeight = scrollHeight = 594，控制区底部均在固定导航上方；主读数区域约180px（离线154px），连接/电量14px，菜单48×48px。整体外框804px。网页外部可整体移动，检测页自身不滚动。

独立 UI 智能体依据 Impeccable 和 Taste Skill 完成样式及只读截图审查，结论适合交给用户审核。原生 nova14 字体、安全区、系统通知和实际设备兼容性尚未验证；网页截图不等于安卓 APK 截图。

样式文件支持本地定时检测更新，保留正在浏览的页面/弹窗。脚本结构或样例数据更新后需刷新预览；刷新会恢复样例状态。
