# 两键尿量检测器固件

工程位置：`F:\ESP32\niaio\git\second sol`。目标芯片 ESP32-S3，ESP-IDF v5.5.5。串口屏作为纯显示设备；GPIO8、GPIO9 两个实体按键控制测量。

## 代码结构

| 层 | 位置 | 职责 |
|---|---|---|
| 入口 | `main.c` | 初始化液滴、按键、串口屏和 U 盘，启动状态机 |
| 应用 | `app/monitor`、`app/S3` | 三态转换、计时、24 小时判断、分钟记录、显示节流 |
| 服务 | `service/urine`、`screen`、`storage` | 尿量解算、TJC 指令、CH376 文件操作 |
| 驱动 | `driver/drop`、`key`、`screen_uart`、`ch376`、`time_svc` | GPIO、UART、软 SPI、时间 |
| 板级 | `bsp/pin_map.h` | 硬件引脚定义 |

## 操作

| 当前状态 | 按键 1（GPIO8） | 按键 2（GPIO9） |
|---|---|---|
| 待开始 | 开始新测量并分配新文件 | 无动作 |
| 测量中 | 暂停 | 复位到待开始 |
| 暂停 | 继续同一次测量 | 复位到待开始 |

按键低有效，约 60 ms 软件消抖，按住不连发。暂停期间不计时间或液滴。串口屏只显示，不再接收登录或操作命令。

## 计量、提示与记录

- 每滴默认 `0.5 ml`，定义于 `service/urine/urine.h`，**必须按实物标定**。GPIO10 检测上升沿，0.5 秒内的重复边沿被过滤。
- 运行时间是有效测量时长，不是实时时钟时间。实时速率按最近有效滴间隔计算，7 秒无新滴归零。
- 达到 2,000 ml 立即显示尿袋满。有效测量满 24 小时时固定首次结论：`<100 ml` 无尿，`100–<400 ml` 少尿，`>2500 ml` 多尿；其余为正常。满袋且多尿显示“尿袋满/多尿”。
- 每次新测量分配 `/U0000001.TXT` 等独立文件；每个整分钟写入本分钟尿量及平均速率。暂停继续写同一文件。无 U 盘仍可计量，存储恢复后开始记录，缺失分钟不补写。
- 电池 ADC 驱动仍是占位实现，本版不启用。原 `S1/S2/S4` 文件保留作历史参考，但不编入构建。

屏幕的完整通信格式见工程根目录的《单片机与串口屏通信格式.md》。

## 构建

本目录的旧 `build/` 缓存指向原 `second` 工程。请从 `second sol` 工程根目录使用独立构建目录：

在已激活 ESP-IDF v5.5.5 环境的终端运行 `idf.py -B build-sol build`。

`flash.bat` 已指定 `build-sol`，仅在连接实机且确认串口后运行。
