# service/storage：按测量编号保存记录

每个新测量分配一个独立文件：从 `/U0000001.TXT` 起按编号扫描 U 盘上已存在的文件，取第一个空号（`storage_create_session()`，编号上限 `/U9999999.TXT`），写入表头后关闭。暂停后继续沿用同一文件。

## 1. 文件格式

表头只在**新建文件**时写一次（`STORAGE_HEADER`，列宽宏与数据行共用，改 `storage.h` 一处两处同时变）：

```text
时间(hh:mm:ss)    尿量(ml)            平均流速(ml/h)
00:01:00          1.6ml               96.0ml/h
00:02:00         12.3ml              738.0ml/h
```

数据行由 `app/S1` 组帧（`REC_ROW_FMT`，表头与数据都**左对齐**，列间 4 空格、行尾 2 空格）：

- 第 1 列：会话时间 `hh:mm:ss`（有效测量时间，暂停不计时）
- 第 2 列：**本分钟尿量** = 本分钟末累计总量 − 上一分钟标记时的累计总量
- 第 3 列：**本分钟平均流速** = 本分钟尿量 × 60（ml/h）；整分钟一滴没有就写 `0.0ml 0.0ml/h`

## 2. 写入方式：文件不常开

`app/S1` 每到新的整分钟进入互斥保护的写盘事务区：暂关液滴中断，暂停串口屏和手机状态推送（Wi-Fi连接保持），保留storage INFO与CH376 WARN/ERROR。退出后恢复原采集状态、推送与日志等级；嵌套仅最外层恢复，成功和失败均有完成提示：

```text
storage_open_session(stem)   /* 0x2F 设名 + 0x32 打开；已存在则 0x39 定位到文件末尾(追加) */
storage_write_open(line)     /* 0x3C/0x2D/0x3D 写入一行 */
storage_close_session()      /* 0x36 关闭并更新目录项 */
```

文件同时处于打开状态只有几十毫秒，拔盘/断电最多丢当前这一分钟。每个文件操作函数都**不做** `0x30`/`0x31` 介质同步——那只能在"无文件打开"时做。

## 3. 断盘容错

- 无 U 盘也能继续计量：`app/S1` 每 5 秒重试一次（`STORAGE_RETRY_MS = 5000`）。
- 恢复时按情况选择：本次已分配过文件名 → `storage_ensure_session()` 恢复它；还没有文件名 → `storage_create_session()` 新分配一个。
- 恢复后从当前分钟继续记录；**此前未写入的分钟不缓存、不补写**。
- 测量中 U 盘不可用时**屏上不再有任何提示**：原先"每 5 秒插播 1 秒 `U盘异常`"的做法已随状态栏文本链路一并删除（固件里已没有这个插播接口），只剩串口告警与每 5 秒一次的重试。

## 4. CH376 使用约定（踩过的坑）

- 文件名必须是**大写 8.3**：`SET_FILE_NAME(0x2F)` 按手册只支持 8.3 短文件名且字母必须大写。传小写时芯片能用同样字符串打开（日志看着"成功"），但写进目录项的名字是坏的 → 电脑上打不开/找不到。当前文件名由 `U%07lu` 生成（`make_fname()` 负责转大写 8.3），不涉及用户名。
- **`0x30` 之后必须补 `0x31`**：`CMD_DISK_CONNECT(0x30)` 会重新枚举 USB 设备、作废已挂载的 FAT 上下文，不重新 `DISK_MOUNT(0x31)` 的话，后续文件操作一律返回 `0x42 ERR_MISS_FILE`（哪怕文件就在盘上）。`media_sync()` 里这两个命令永远成对出现，且只在"无文件打开"时调用（`storage_create_session()` / `storage_ensure_session()` 开头）。
- **落盘验证**：新建文件后先重新挂载（强制芯片丢掉内部 FAT/目录缓存、重读磁盘）再打开，能打开且长度 ≥ 表头长度，才认为文件真的写进了 U 盘（否则拔盘/断电就没了）。
- 开机的 `TEST.TXT` 自检**已删除**（它每次上电重建文件，导致"电脑上删掉的文件又出现"）。
- 挂载失败（`0x31` 返回失败）不当致命错误，仅告警继续。

## 5. 接口（`storage.h`）

| 接口 | 说明 |
|---|---|
| `storage_init()` | CH376 软 SPI + 进 USB 主机模式 + 检测磁盘 + 挂载；失败返回非 `ERR_OK`（`main.c` 告警后继续运行） |
| `storage_create_session(stem, size)` | 分配新的 `/U0000001.TXT`…，写表头并做落盘验证；`stem` 至少 9 字节 |
| `storage_ensure_session(stem)` | 断盘后恢复本次会话文件；已存在则保留原内容，不存在则新建 + 表头 |
| `storage_open_session(stem)` | 打开本次文件并定位末尾，供当分钟追加 |
| `storage_write_open(text)` | 往"当前打开的文件"续写文本（文件保持打开，可多次调用） |
| `storage_close_session()` | 关闭当前文件并清状态（暂停/复位时调用） |

> 注意：`stem` 是**不带扩展名的 8 字符编号**（如 `U0000001`），函数内部按下发 `/<stem>.TXT`。
