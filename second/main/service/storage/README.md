# service/storage — U盘存储服务（桥接 driver/ch376）

> app 层(monitor / S3) 通过本模块操作 U 盘文件，不直接碰 CH376。
> 是 `driver/ch376` 的**唯一上层调用方**。被动服务：不建任务、不依赖 app。

---

## 1. 文件生命周期

```
login   → storage_create_user(user)   只保证文件存在（不存在则建 + 写表头），不保持打开
start   → S3 记住用户名；写盘时才真正打开
每分钟  → storage_open_user()  打开 + 定位到文件末尾(追加)
          storage_write_open() 写一行
          storage_close_user() ★ 立刻关闭 —— 目录项/FAT 落盘，拔盘最多丢这一分钟
stop    → S3 清掉用户名（此后不再写盘）
reset   → 同上
```

**文件不常开**：全程只有"写一行"那几十毫秒是打开状态。

---

## 2. 接口

| 接口 | 说明 |
|---|---|
| `storage_init()` | CH376 SPI → 主机模式 → 检测磁盘(0x30) → 挂载(0x31) |
| `storage_create_user(user)` | 介质同步 → 文件不存在则**新建 + 写表头**；已存在则保留原内容 |
| `storage_open_user(user)` | 打开 `<user>.TXT` 并把写指针**定位到文件末尾**（追加），保持打开 |
| `storage_write_open(text)` | 往当前打开的文件续写 |
| `storage_close_user()` | 关闭文件 + 清状态 |

> `storage_open_user()` / `storage_write_open()` 会返回 `ERR_NOT_READY`（U盘未就绪）或 `ERR_FAIL`（CH376 报错），由调用方(S3)打日志跳过。

## 3. 文件名规则（**重点，踩过坑**）

### 必须是大写 8.3 短文件名

CH376 的 `SET_FILE_NAME (0x2F)` 按手册**只支持 8.3 短文件名、且字母必须大写**
（参考工程验证过的就是 `/ASD.TXT`）。

传小写/空格/中文时芯片行为未定义：**它自己能拿同样的字符串 `OPEN` 回来**
（日志看着"创建成功、长度正确"），但写进目录项的名字是坏的 →
**电脑上"打不开 / 说找不到文件"**。

### 转换规则（`make_fname()`）

| 输入字符 | 输出 |
|---|---|
| `a`~`z` | 转成 `A`~`Z` |
| `A`~`Z` `0`~`9` `_` `-` | 原样 |
| 空格 / 中文 / 其它 | 换成 `_` |
| 超过 8 个字符 | 截断（打 WARN） |

```
abc     → /ABC.TXT
hoht    → /HOHT.TXT
张三    → /__.TXT      ← 中文会被压成下划线，不同中文名会撞名!
```

> ⚠️ **中文/超长用户名会互相覆盖**。要保留原名必须走 CH376 的长文件名(LFN)流程，或改用
> "文件名用编号 + 用户名写进文件内容"的方案。当前未实现。

## 4. 记录文件格式

### 表头（只在**新建**文件时写）

```
时间(hh:mm:ss)    尿量(ml)            平均流速(ml/h)  
```

### 数据行（每分钟一行）

```
00:01:00          1.6ml               96.0ml/h  
00:02:00         12.3ml              738.0ml/h  
```

- **本分钟尿量** = 本分钟末累计总量 − 上一分钟标记时的累计总量
- **本分钟平均流速** = 本分钟尿量 × 60（ml/h）
- 行尾 `\r\n`
- 某一分钟一滴都没有 → 照写 `0.0ml 0.0ml/h`
- 第 0 分钟（start 瞬间）**不写**

### 列布局宏（表头与数据行共用，改一处两处一起变）

```c
#define REC_COL1_W   14         /* 列1 内容宽: "时间(hh:mm:ss)" / "00:01:00" */
#define REC_COL2_W   12         /* 列2 内容宽: "尿量(ml)"       / "12.3ml"   */
#define REC_GAP1      "    "    /* 列1 → 列2 : 4 空格 */
#define REC_GAP2      "    "    /* 列2 → 列3 : 4 空格 */
#define REC_TAIL      "  "      /* 行尾补白  : 2 空格 */

/* 把宏值转成字符串，拼出格式串（避免列宽改了两边不同步） */
#define REC_STR_(x)   #x
#define REC_STR(x)    REC_STR_(x)

#define REC_ROW_FMT \
    "%-" REC_STR(REC_COL1_W) "s" REC_GAP1 \
    "%-" REC_STR(REC_COL2_W) "s" REC_GAP2 \
    "%s" REC_TAIL

#define STORAGE_HEADER \
    "时间(hh:mm:ss)"  REC_GAP1 \
    "尿量(ml)"        REC_GAP2 \
    "平均流速(ml/h)"  REC_TAIL "\r\n"
```

> 表头与数据都**左对齐**：每列数据的第一个字符正好在该列表头第一个字的下方。
> 按**等宽字体**计算，中文占 2 格；用非等宽字体看会不齐（字体问题，改代码也没用）。

S3 侧只写一行：

```c
snprintf(line, sizeof(line), REC_ROW_FMT, c1, c2, c3);   /* c1=时间 c2=尿量 c3=流速 */
```

## 5. 介质同步 `media_sync()`（**重点，踩过坑**）

CH376 挂载后会把 **FAT 表 + 根目录扇区缓存在芯片内部 RAM**。
如果 U 盘被拔下来（在电脑上改过）再插回板子，而板子没重新挂载，
芯片就会拿着**过期的目录缓存**继续读写 —— 表现为：

- 电脑上删掉的文件"复活"
- 板子新写的文件在电脑上找不到
- 两边交替写导致 FAT 错乱、文件打不开

### 调用时机

`storage_create_user()` 开头（即 `login` 和 `start` 时）调用一次 ——
**此时必须没有文件打开**，因为 `0x30` 会打断芯片的文件上下文。

> `storage_open_user()` 里**不调用**它：那个函数是在"每分钟写盘"的临界区内被调用的，
> 而 `media_sync` 要 `0x30+0x31` 约 200ms，不能放进临界区。

### 实现要点（**必须 0x30 + 0x31 成对**）

```c
uint8_t st = CH376T_DiskCheckRaw();        /* 0x30 检测介质在位 */
if (st == USB_INT_DISCONNECT) {            /* 0x16 已拔出 */
    s_ready = false; return ERR_NOT_READY;
}
/* ★ 在位(0x14)/刚插回(0x15)/其它：统一重新挂载一次。
   CMD_DISK_CONNECT(0x30) 会让芯片重新枚举 USB 设备、作废已挂载的 FAT 上下文，
   所以【发完 0x30 必须补一次 0x31】，否则后续文件操作一律返回
   0x42(ERR_MISS_FILE 文件未找到) —— 哪怕文件就在盘上! */
if (!CH376T_DISK_MOUNT()) { s_ready = false; return ERR_NOT_READY; }
```

## 6. 落盘验证

新建文件后，**先重新挂载（丢掉芯片内部缓存、强制重读磁盘）再打开**：

```
落盘验证通过: /ABC.TXT 确实在U盘上, 长度 48 字节
落盘验证失败: 重新挂载后打不开 /ABC.TXT → 文件没真正写进U盘!
```

`storage_create_user()` 里的普通"重新打开看长度"可能只是**读芯片缓存**，证明不了落盘；
这个验证做不了假。

## 7. 错误码含义（排查用）

| CH376 状态 | 含义 | 常见原因 |
|---|---|---|
| `0x14` | `USB_INT_SUCCESS` | 正常 |
| `0x42` | `ERR_MISS_FILE` 文件未找到 | ① 文件确实不存在 ② **0x30 之后忘了 0x31 重挂载** |
| `0x1F` | `USB_INT_DISK_ERR` 磁盘操作失败 | U盘写保护 / 空间不足 / 接触不良 |
| `0xFF` | `wait()` 等中断超时 | SPI 时序 / INT 脚 / 供电 |

## 8. 已知限制

1. 同一用户重复登录 → **追加**到原文件末尾（不覆盖、也不重复写表头）
2. 中文/超长用户名会被压成 `_`，可能撞名（见 §3）
3. 记录时间是**会话计时**（从 `start` 起算），不是绝对时间（无 RTC）
4. 拔盘前建议先 `stop`/`reset`；虽然文件只在写盘时短暂打开，但仍在写盘瞬间拔盘会丢当前这一分钟
