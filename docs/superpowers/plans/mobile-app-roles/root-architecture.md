目标：完成P0；冻结protocol-v1、ui-v1、DTO/接口、文件所有权和基线；执行真实多级调度。完整需求在上级指定的work-plan中，用户已确认Android、只发时分秒、中间service层解析/打包。

权限：创建任务文档、隔离工作树、公共合同与集成分支。不得覆盖未提交修改，不自动stash/reset。任何修改公共合同由你统一管理。

接收：必须检查实际diff、测试输出与跨组一致性；不能相信“已经完成”的口头结论。你拥有最终ACCEPTED权限；其他角色不能自验收为终态。

输出：基线记录、版本化合同、所有权表、任务包及各阶段通过/阻塞证据。不得把计划当成已实现软件。
