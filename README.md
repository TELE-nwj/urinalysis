### 已完成

- **分层架构**：`main.c`（初始化编排）→ `app`（状态机）→ `service`（screen / storage / urine）→ `driver`（ch376 / drop / screen_uart / time_svc）→ `bsp`（引脚、错误码），依赖方向单向，禁止反向
- **串口屏状态机 S1~S4**：S1 待登录 → S2 已登录 → S3 测量中 → S4 暂停；`app/monitor` 是唯一的状态切换点，用单个 `switch(cmd)` 分发
- **命令协议**：`@用户名@命令` + 行尾；行尾兼容 `\r`、`\n`，以及串口屏实际发出的字面 `/n`
- **U 盘记录**：S3 期间每分钟往 U 盘追加一行（时间 / 该分钟尿量 / 平均流速）；写盘在临界区内完成（停中断、暂停推屏），写完立即关文件以保证目录项落盘
- **速率归零**：连续 7 s 无新滴，速率显示归零
- **复位**：任意状态、任意用户都可触发；复位自动关闭文件并清空数据
- **上电首帧兼容**：解决上电或复位后屏发来的首帧垃圾字节导致第一条登录命令解析失败的问题
- **代码清理**：删除与"U 盘每分钟写一行"功能重复的 `service/record` 模块及其全部调用点

### 硬件接线

| 功能 | 引脚 |
|---|---|
| 串口屏 UART1 | MCU TX = `GPIO17` → 屏 RX；MCU RX = `GPIO18` ← 屏 TX，115200 8N1 |
| 滴传感器 | `GPIO10`（上升沿中断，0.5 s 消抖） |
| CH376 软 SPI | SCS = `GPIO2`、SDI = `GPIO41`、SDO = `GPIO40`、SCK = `GPIO42`、INT = `GPIO1` |

### 已知限制 / 待办

- 每滴容积按 `0.05 ml` 估算（`URINE_DROP_ML_DEFAULT`），**尚未标定**
- CH376 的 `SET_FILE_NAME(0x2F)` 只支持**大写 8.3 短文件名**；用小写会让目录项损坏，导致 PC 端报"找不到文件"
- `driver/key`、`driver/battery` 已实现但**尚未接入业务逻辑**
- 速率 7 s 无新滴归零，在现场**尚未复验**
