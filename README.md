## 版本演进与关键历程

### first → second：架构重构

把原型代码按 `main → app → service → driver → bsp` 重新分层，依赖方向单向，禁止反向。

### second → third：功能集成

- 三态状态机（待开始 / 测量中=S1 / 暂停=S2），两键短按控制
- 串口屏 `data.t0~t7` 显示，U 盘每分钟追加一行
- Wi-Fi SoftAP + WebSocket，手机可远程查看和下发指令

### third 正式版 → 测试版：U 盘写盘故障排查

现场出现 **U 盘文件损坏**：`U0000003.TXT` 首簇为 0 却有 56 字节长度，数据实际写到了 FAT2 区域。

| 版本 | 措施 | 结果 |
|---|---|---|
| **C 版** | 会话保护：暂停继续不换号、创建失败不重建 | 不解决根因 |
| **D 版** | FAT 预检 + 双 FAT 校验 + 数据簇核验 | ❌ **实机失败** |
| **E 版** | 交接阶段严格只走厂商流程（`0x1E→0x2D→0x3D→0x14`） | 待实测 |

**D 版为什么失败**（重要教训）：

`BYTE_WRITE` 返回 `0x1E`（芯片请求提供数据）的阶段，内部寄存器窗口映射的是**临时数据**。D 版在这个窗口插入了 `READ_VAR` 探针去读文件状态，读到不稳定值 → 误判地址异常 → 主动拦截 → **56 字节表头根本没发出去**，最终文件只有 1 字节 `0x2E`。

> **观察者效应**：为了"看清楚"而在协议临界窗口插入探针，结果改变了被观察对象的行为。

**E 版的修正**：交接窗口内只走厂商流程，探针全部移到窗口外；保留请求前 FAT 检查、完成后字段校验、关闭后回读验证。

### third → fourth：修复落地 + 轻量化

**`fourth/正式版/`** —— 把 E 版修复合回 third 基线：
- 新增 `ch376_diag.c`：BPB/FAT 解析、物理扇区读、写前拦截、写后回读
- storage 收紧：挂载失败即失败、禁止现场重建、先锁编号再创建、追加长度校验
- **日志保持 third 原版简洁风格**（测试版的 93 条排查日志已全部清除，固件 831 KB）

**`fourth/轻量版/`** —— 去除手机链路的纯本地方案：
- 删除全部 WiFi / HTTP server / 手机适配器（8 个源文件 + 6 个组件依赖）
- **固件从 831 KB 降到 207 KB（-75%）**
- 启动优化：日志降噪（省 250~350 ms）、屏初值帧 9→5、存储初始化超时 1.7s→0.85s
- 启动时间：插 U 盘约 0.3~0.6 s，无 U 盘约 0.9~1.2 s

## 硬件接线

| 功能 | 引脚 |
|---|---|
| 串口屏 UART1 | MCU TX = `GPIO17` → 屏 RX；MCU RX = `GPIO18` ← 屏 TX，115200 8N1 |
| 滴传感器 | `GPIO10`（上升沿中断，0.5 s 消抖） |
| CH376 软 SPI | SCS = `GPIO2`、SDI = `GPIO41`、SDO = `GPIO40`、SCK = `GPIO42`、INT = `GPIO1` |
| 按键 | 2 路：`GPIO8`、`GPIO9`（低有效 + 内部上拉） |
| 电池检测 | `GPIO7`（ADC 分压） |

## 快速开始

### 编译固件

```powershell
# 任意 fourth/third/second 工程目录下
.\build.ps1
```

### 烧录

```powershell
.\flash.ps1 -Port COM<下载口>
```

**注意**：烧录必须用真实的下载口；日志口不能当下载口用。烧完必须看到 `Hash of data verified` 才算成功。

### 上位机

```powershell
cd 手机与上位机\串口上位机
python main.py
```

需要 `PyQt5`、`pyserial`；测试用 `python tests/test_parser.py`。

## 已知限制

- 每滴容积按 `0.5 ml` 估算（`URINE_DROP_ML_DEFAULT`），**尚未实机标定**
- CH376 的 `SET_FILE_NAME(0x2F)` 只支持**大写 8.3 短文件名**，小写会损坏目录项
- U 盘上已有的 FAT 损坏不会被固件修复
- `fourth/正式版` 与 `fourth/轻量版` 均**未完成实机验收**（E 版修复待真机验证）
